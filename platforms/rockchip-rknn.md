# Rockchip / RKNN 分析适配

锁定目标 SoC、RKNN-Toolkit2 版本、板端 runtime/驱动及 NPU 核配置；不把所有 RK 型号视为相同架构。

对应模型转换日志、算子支持限制、量化配置和编译后图，检查布局转换、分区、回退、各核放置及内存搬运。使用本版本提供的性能/内存分析接口，并确认字段含义与调用边界；不要将原图节点数量等同硬件任务数量。

重点验证逐通道量化、输入预处理是否折入、实际输入输出布局及零拷贝/DMA 路径。板端 DDR 内存和 runtime 分配与 TFLM Arena 概念不同，不强行套用 Arena 指标。

约束来源：[厂商 RKNN-Toolkit2 仓库](https://github.com/airockchip/rknn-toolkit2) 中当前版本的手册、支持表、示例和变更记录；配合实际转换日志与驱动。

此页为适配框架，具体支持条件和命令须读取目标版本后填写。
