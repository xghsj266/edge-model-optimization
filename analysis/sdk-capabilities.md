# SDK 与硬件约束提取

为每项约束记录：值/限制、适用芯片和版本、文档章节或源码符号与行号、证据类型、未知项、对应模型节点。

| 约束 | 查找位置 | 影响 |
|---|---|---|
| 算子支持条件 | 支持表、编译器检查/降低源码、编译日志 | dtype、形状、广播、group、padding 是否触发回退 |
| 布局与对齐 | 内核说明、张量地址、生成代码 | 通道补齐、重排、DMA 对齐及额外缓冲 |
| 内存层级 | 手册、链接脚本、配置文件 | SRAM/TCM/PSRAM/DDR/Flash 容量与可达性 |
| 融合与级联 | 调度报告、编译源码、生成指令 | 是否物化中间张量、是否重复读取 |
| 分区与调用 | runtime、委托/自定义算子接口 | CPU/NPU 往返、复制和启动次数 |
| 缓存与同步 | clean/invalidate、DMA、等待和中断路径 | 数据一致性、重复维护及等待开销 |

固定 SDK、编译器和运行时版本及厂商补丁。目录名或营销型号不能替代芯片/NPU 配置。最新公开手册若与本地 SDK 不同，保留差异，不默认为本地具备新功能。

手册只给出能力上限时，继续查实际构建开关、源码和报告。找不到的限制写未知，不从其他平台借一个数值。
