# 模型结构分析

产出节点/子图表：原始位置、导出位置、输入输出形状与布局、dtype、量化参数、权重字节、MACs、逻辑张量字节、生产者/消费者、分支与重汇合点。

优先检查：

- 大分辨率阶段的通道扩张、逐元素链、分支同时存活和重复布局转换。
- Conv 的 group、kernel、stride、padding、dilation；明确深度卷积与一般分组卷积。
- PReLU/BN 等高层操作在导出后是否展开，常量是否被保留为运行时算子。
- 重复量化/反量化、尺度不一致引入的重定标、浮点孤岛。
- 权重统计：逐通道范围、异常值、零比例和奇异值能量。零多只说明潜在压缩机会，需核实硬件能否跳零。

静态估算规则：普通分组 Conv MACs = N×Ho×Wo×Co×Kh×Kw×Ci/group；不把 1 MAC 与 2 FLOPs 混写。逻辑张量字节 = 元素数×dtype 字节，仅作为下界；对齐、压缩、分块及复用以编译报告为准。

动态形状、控制流和输入相关输出长度需列出范围。相同输入尺寸仅在静态执行路径及分配策略不变时，才通常对应固定工作区需求。不要反序列化来源未知的可执行 pickle 权重；优先安全权重格式及已有图文件。
