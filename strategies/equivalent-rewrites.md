# 等价改写

这是 Skill 的核心推导路径：先标定代数前提，再核对量化和硬件代价，形成可执行且可证伪的改写候选。

每条推导按以下顺序记录：

1. 原表达式及其图节点、形状、广播、分支消费者。
2. 改写表达式、权重/常量映射和成立条件，说明等价关系覆盖的输入域。
3. 目标后端为何可能更高效：实际支持的原生算子、融合、物化、重排或调度变化。
4. 浮点与目标量化格式分别验证，记录舍入、饱和或重定标差异及用户允许的容差。
5. 比较编译结果：主目标、其他代价，以及对应的映射变化。数学证明不能替代性能验证。

区分实数恒等、浮点容差内一致、INT8 逐值一致和任务精度保持。若只有实数证明及样本数值对照，就按这一证据范围表述，不能声称所有量化输入均已严格等价。

| 候选 | 前提与修改 | 验证重点 |
|---|---|---|
| 推理 BN 折叠 | eval 模式使用固定统计；W'=aW，b'=a(b−μ)+β，a=γ/√(σ²+ε) | 输出通道轴、分组、偏置和重新量化 |
| Concat 后 BN 分配到分支 | 按拼接通道切分 BN 参数，各分支先做仿射 | 连接轴、分支其他消费者，能否继续折入卷积 |
| 恢复原生 PReLU | 用实际导出表达式识别 ReLU(x)+α(x−abs(x))/2 | α 广播及符号、原生支持、重定标和峰值缓冲 |
| 合并连续线性变换 | 中间无非线性或数据相关行为 | padding/bias 边界、权重膨胀，分解层直接执行可能更省计算 |
| 分组卷积重表达 | 逐组权重映射和通道交换证明 | 搬运、额外中间结果、INT8 累加舍入，不因等价就优先采用 |

PReLU 写成 maximum(x, αx) 仅在 α≤1 等对应条件成立时等价；不能假设所有训练权重都满足。系数吸收也需逐通道证明符号和非线性可交换条件。

候选改法需具体到节点匹配条件、权重/属性变换、拒绝条件和回滚产物。先比较浮点，再比较目标量化语义；整图数值或任务指标不满足约定就不称“无损”。
