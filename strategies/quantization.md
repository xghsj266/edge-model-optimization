# 量化优化

先读取真实 scale、zero-point、量化轴、权重位宽、累加器和舍入/饱和规则。全 INT8、仅权重量化和浮点激活不能互称。

机会顺序由证据决定：

- 逐层误差和异常值集中 → 检查校准分布、逐通道权重、尺度均衡、偏置修正或 QAT。
- 相邻逐元素操作重复重定标 → 检查共享尺度能否省算子/缓冲；尺度统一会改变量化误差，并非天然等价。
- 编译出现浮点孤岛/回退 → 对照 dtype、广播和支持限制，优先消除边界成本。
- 位宽降低 → 先确认目标算子和打包布局支持；体积收益不保证速度收益。

变更输入/权重尺度时，偏置量化通常需要随之更新；具体公式和粒度以目标量化规范为准。拒绝只修改 flatbuffer 尺度而不重算受影响常量的做法。

数值验证固定预处理、输入量化和输出反量化。5 张图可发现实现错误，不能证明识别精度无损；任务准确率、阈值和全量评估按授权另行验证。
